# tools

Operations and archive tools. Most of them run on the Mac. They cover HF archive and transfer, board watch, the SOP site, remote status checks of the training hosts, and the name check before a submission.
All credentials come in through environment variables or stdin. For the use of the HF archive, see [Section 7 of the engineering handbook](../docs/engineering/v2d-track2-engineering-handbook.zh.md) (in Chinese).

`repo_index.py` generates the file indexes in the README of each directory. After you add or delete files, run `git add`, then run `python3 tools/repo_index.py`.
`--check` only checks whether an index is out of date.
