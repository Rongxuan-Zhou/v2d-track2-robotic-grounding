# stages/retarget

Human and object trajectories → G1 + Dex3 reference motion (motion parquet: joint targets, palm poses, object pose, contact labels). This stage uses the official `soma_to_g1`
retargeter v0.4.0, frame by frame, with no interpolation. The official source code is not modified. The parts that depend on Isaac run in the `robotic-grounding:latest` container. For the method, see
[Section 4.1 of the engineering handbook](../../docs/engineering/v2d-track2-engineering-handbook.zh.md) (in Chinese). For the contract, see [`docs/contracts/retarget.md`](../../docs/contracts/retarget.md).

Entry points: `challenge_to_soma.py`, `soma_flex.py`, `run_soma_to_g1.py` (wrappers around the official retargeter), `one.sh` (one episode).
The reference quality checks are `ref_*.py` and `check_support_alignment.py`. `contact_relabel.py` makes the Tier 1 `c10` contact windows.
